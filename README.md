## 📖 About

This is my personal developer portfolio — designed to give recruiters and engineers a clear picture of who I am, what I've built, and how I work. Built from scratch using React + Vite + Tailwind CSS and deployed on Netlify with continuous deployment from GitHub.

### ⚡ Performance-First Build
- Built with **Vite** for near-instant HMR and optimized production bundles
- Lighthouse-friendly structure with fast load times

### 📱 Fully Responsive Design
- **Tailwind CSS** utility classes ensure a seamless experience across mobile, tablet, and desktop
- No layout shifts or overflow issues on any screen size

### 🎨 Smooth Animations & Transitions
- Subtle entrance animations and hover effects for a polished, professional feel

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/navaleprachi/Portfolio-Website.git
   cd Portfolio-Website
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production**
   ```bash
   npm run build
   ```

5. **Preview the production build**
   ```bash
   npm run preview
   ```

## 🚢 Deployment

This site is deployed on **Netlify** with continuous deployment — every push to `main` automatically triggers a new build and goes live within minutes.

To deploy your own fork:
1. Push the repo to GitHub
2. Connect it to [Netlify](https://netlify.com) → **New site from Git**
3. Set build command: `npm run build`
4. Set publish directory: `dist`
5. Deploy — Netlify handles the rest
